### 🚀 About Me

I'm an **electrical engineer** (BSc, University of Calgary) who writes **embedded software**. Most recently I built locomotive control systems at On Track Controls: a **Qt/QML + Rust** HMI that replaced $2,000-per-unit custom display hardware, a multi-threaded **Rust** test system for control boards, and **C firmware** for CANbus EEPROM flashing on **STM32** and **TI** microcontrollers — including debugging motor controllers on CPKC's hydrogen locomotive program.

Off the clock I run a **Proxmox homelab** (TrueNAS, LXC fleet, Grafana/Prometheus monitoring) that hosts my own scheduled data pipelines, and I automate anything I have to do more than twice — whether that means writing code or welding something.
